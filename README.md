# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».Тема проекта: «HTML и CSS: разработка многостраничного сайта».

## Структура проекта

-  index.html – главная страница;
-  catalog.html – каталог товаров;
-  category.html – страница категории «Книги»;
-  about.html – о проекте;
-  delivery.html – доставка и оплата;
-  contacts.html – контактная информация;
-  css/style.css – файл стилей;
-  js/main.js – файл JavaScript;
-  images/ – папка для изображений;
-  README.md – описание проекта;
-  .gitignore – список файлов, исключённых из Git.

## Используемые технологии
HTML5, CSS3, минимальный JavaScript, Git и GitHub. CSS-фреймворки и сторонние библиотеки не используются.

- Семантика: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Общее меню, уникальные заголовки и описания страниц, якорные ссылки.
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- Flexbox для меню и содержимого карточек; Grid для товаров, каталога и подробной карточки.
- БЭМ: `site-nav__link--active`, `product-card__title`, `order-form__field` и другие блоки и элементы.
- Позиционирование: `relative` у карточки, `absolute` у бейджа, `sticky` у шапки и фильтра, `fixed` у кнопки «Наверх»; `z-index` задаёт порядок отображения.
- Таблицы с `caption`, `thead`, `tbody`, `th`, `td` и областью заголовков `scope`.
- Формы с `label`, `id`, `name`, `required`, `type="email"` и проверкой формата телефона.
- Модальное окно `<dialog>`: открытие с выбранным товаром, закрытие кнопкой и клавишей Escape. Браузер управляет фокусом.

## Четыре самостоятельные доработки для практической
Выбраны из пункта 14 методички:

1. Блок часто задаваемых вопросов: три раскрываемых вопроса на главной, без дополнительного JavaScript (`details` и `summary`).
2. Расширенная таблица характеристик: семь строк для каждого товара, включая вариант карточки, обязательные данные и условия демонстрационной заявки.
3. Sticky-фильтр каталога: боковой блок остаётся видимым при прокрутке на широком экране. На узком экране закрепление отключено. Сам отбор товаров остаётся статическим макетом по заданию.
4. Варианты карточек через БЭМ-модификаторы: `product-card--featured`, `product-card--discount`, `product-card--unavailable`. Они различаются бейджами, границами, ценой и состоянием кнопки. Недоступный товар нельзя заказать из его карточки.

Проект должен включать:

-  главную страницу;
-  страницу каталога;
-  страницу карточки товара или услуги;
-  страницу оформления заявки;
-  страницу контактов;
-  семантическую HTML-разметку;
-  внешний CSS-файл;
-  базовую навигацию;
-  оформление основных блоков страницы.

## CSS-архитектура
В проекте используются:

-  CSS-переменные в :root;
-  единая шкала отступов;
-   переменные для цветов и скруглений;
-  состояния :hover, :focus-visible, :disabled;
-  визуальная подсветка ошибочных полей через aria-invalid;
-  структурированный файл css/style.css.
## Использование Flexbox и Grid
В проекте используются:

-  Flexbox для основного меню;
-  Flexbox для внутренней структуры карточек товаров;
-  CSS Grid для сетки карточек;
-  CSS Grid для страницы каталога с фильтрами и списком товаров.
## БЭМ-структура проекта
В проекте используются следующие БЭМ-блоки:

-  site-header – шапка сайта;
-  site-nav – основная навигация;
-  breadcrumbs – хлебные крошки;
-  hero – первый экран главной страницы;
-  products-grid – сетка товаров;
-  product-card – карточка товара;
-  catalog-layout – структура страницы каталога;
-  catalog-filters – фильтры каталога;
-  order-dialog – модальное окно заявки;
-  order-form – форма заявки;
-  button – кнопка;
-  site-footer – подвал сайта.
