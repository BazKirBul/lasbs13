# Учебный интернет-магазин

Дисциплина: «Фронтенд и бэкенд разработка», 3 семестр, 2026/2027 учебный год.

Автор: Базырцыренов Кирилл Булатович. Группа: ЭФБО-07-25.

## Описание

Многостраничный HTML/CSS-каталог с тремя учебными товарами, характеристиками и формой заявки. Товары, цены и наличие демонстрационные. Реальные продажи, отправка заявок и хранение персональных данных не реализованы.

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

## Просмотр

Для локального просмотра скачайте репозиторий и откройте `index.html` в современном браузере. Установка зависимостей и сборка не нужны.

## Технологии и обязательные элементы

HTML5, CSS3, минимальный JavaScript, Git и GitHub. CSS-фреймворки и сторонние библиотеки не используются.

- Семантика: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Общее меню, уникальные заголовки и описания страниц, якорные ссылки.
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`.
- Flexbox для меню и содержимого карточек; Grid для товаров, каталога и подробной карточки.
- БЭМ: `site-nav__link--active`, `product-card__title`, `order-form__field` и другие блоки и элементы.
- Позиционирование: `relative` у карточки, `absolute` у бейджа, `sticky` у шапки и фильтра, `fixed` у кнопки «Наверх»; `z-index` задаёт порядок отображения.
- Таблицы с `caption`, `thead`, `tbody`, `th`, `td` и областью заголовков `scope`.
- Формы с `label`, `id`, `name`, `required`, `type="email"` и проверкой формата телефона.
- Модальное окно `<dialog>`: открытие с выбранным товаром, закрытие кнопкой и клавишей Escape. Браузер управляет фокусом.

## Четыре самостоятельные доработки для практической

Выбраны из пункта 14 присланной методички:

1. Блок часто задаваемых вопросов: три раскрываемых вопроса на главной, без дополнительного JavaScript (`details` и `summary`).
2. Расширенная таблица характеристик: семь строк для каждого товара, включая вариант карточки, обязательные данные и условия демонстрационной заявки.
3. Sticky-фильтр каталога: боковой блок остаётся видимым при прокрутке на широком экране. На узком экране закрепление отключено. Сам отбор товаров остаётся статическим макетом по заданию.
4. Варианты карточек через БЭМ-модификаторы: `product-card--featured`, `product-card--discount`, `product-card--unavailable`. Они различаются бейджами, границами, ценой и состоянием кнопки. Недоступный товар нельзя заказать из его карточки.

Ещё четыре доработки для будущей контрольной сейчас не выполнялись. Контрольная №2 на CSS-фреймворке не выполнялась: по методичке для неё нужен отдельный репозиторий.

## Как проверить

1. Открыть пять страниц через общее меню; на каждой текущий пункт выделен.
2. Проверить якоря «Преимущества», «Популярные товары», «Контакты» и «Наверх».
3. Перейти из карточек каталога к соответствующим товарам и проверить таблицы и изображения.
4. Открыть заявку на товар 1 или 2: товар выбран в модальном окне. Закрыть кнопкой или Escape.
5. Попробовать отправить пустую форму, неверный e-mail или телефон, не установить согласие: браузер блокирует отправку.
6. Заполнить форму корректно: появляется сообщение о локальной демонстрации без отправки данных. Нажать «Очистить».
7. Проверить закрепление фильтра при прокрутке, три варианта карточек, FAQ и видимый фокус клавишей Tab.
8. В инструментах разработчика проверить `display: flex` у меню и `display: grid` у сеток.
